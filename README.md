# Reading List App

A responsive book-reading tracker built with HTML, CSS and vanilla JavaScript.

## Features

- Add books with a reading status: **Want to Read**, **Reading**, or **Finished**
- Change a book's status at any time
- Filter the collection by status
- Prevent duplicate titles (case-insensitive and ignores extra spaces)
- Limit book titles to 60 characters
- Delete individual books
- Live summary counts for total books, currently reading and finished
- Save the reading list in the browser using `localStorage`
- Responsive layout for desktop and mobile

## Run locally

No installation or build step is required.

1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Deploy on Vercel

1. Push this project to a GitHub repository named `reading-list-app`.
2. Sign in to [Vercel](https://vercel.com/) using GitHub.
3. Select **Add New → Project**.
4. Import the `reading-list-app` repository.
5. Keep the default settings and click **Deploy**.
6. After deployment, copy the live URL.
7. Replace the placeholder below with your deployed URL.
